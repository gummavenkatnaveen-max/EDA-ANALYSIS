# EDA-ANALYSIS
# E-Commerce Sales Data Cleaning and cleaning Data 

## 📌 Project Overview

This project focuses on **data cleaning and Exploratory Data Analysis (EDA)** using Python. The objective is to identify and handle data quality issues in an e-commerce sales dataset and prepare the data for further analysis.

The project uses Python libraries such as Pandas and NumPy to inspect the dataset, identify missing values, remove duplicate records, and standardize inconsistent category and payment method values.

## 🎯 Objectives

- Understand the structure and dimensions of the dataset.
- Inspect column information and summary statistics.
- Identify missing values and duplicate records.
- Clean inconsistent category names.
- Standardize payment method values.
- Prepare a cleaner dataset for further analysis.

## 🛠️ Tools and Technologies

- **Python** – Data cleaning and analysis
- **Pandas** – Data manipulation and preprocessing
- **NumPy** – Numerical operations
- **Jupyter Notebook** – Interactive coding and analysis

## 🔍 Project Workflow

1. Import the required Python libraries.
2. Load the e-commerce sales dataset.
3. Examine the number of rows and columns.
4. Inspect data types and statistical summaries.
5. Identify missing values.
6. Remove duplicate records.
7. Standardize inconsistent category names.
8. Clean inconsistent payment method values.
9. Prepare the data for further analysis.

## 📊 Key Skills Demonstrated

- Data inspection
- Data quality assessment
- Duplicate removal
- Missing-value analysis
- Text standardization
- Data preprocessing using Pandas
- Exploratory data analysis

## 📁 Project Files

- `EDA ANALYSIS.ipynb` – Jupyter Notebook containing the data cleaning and analysis code.
- `ecommerce_sales_dirty_2024_2025.csv` – Input dataset used for the project.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Install Python and Jupyter Notebook.
3. Install the required libraries:

   ```bash
   pip install pandas numpy jupyter
   ```

4. Place the CSV dataset in the same folder as the notebook.
5. Open the notebook and run the cells.

This project demonstrates the importance of data cleaning before performing meaningful analysis. By identifying duplicate records and standardizing inconsistent values, the dataset can be made more suitable for further exploratory analysis and business reporting.
